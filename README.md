# Reverse Panels Beta

Beta builds of **Reverse Panels**, a native comic reader for Kavita, OPDS, Nextcloud, iCloud Drive
and local files. This repository only hosts the app builds; it contains no source code.

## Install with SideStore (or AltStore)

1. Set up [SideStore](https://sidestore.io) on your iPhone or iPad.
2. In SideStore, open **Sources**, tap **+**, and add:
   ```
   https://raw.githubusercontent.com/josh-eg112/reverse-panels-beta/main/source.json
   ```
3. Open the **Reverse Panels Beta** source and install **Reverse Panels**.
4. New betas appear as updates in SideStore. Refresh apps at least every 7 days.

Requires iOS 17 or later. On first launch a short intro explains how to add your comics.

## Support Reverse Panels

Reverse Panels is free and built in spare time. Right now betas go out through SideStore, which means
re-signing every 7 days. An Apple Developer licence ($99 USD/year) would move it to TestFlight and,
eventually, the App Store.
